결제 게이트웨이 블록 분해

루트 하나에 블록 셋, 각 블록에는 그대로 인용할 수 있는 고정 ID가 붙는다. 그림에는 배지·이름·짧은 흐름만 그리고, 입력·출력·제약·구현 경로는 캔버스가 아니라 메타데이터에 담는다.

THE HEADLINE

모든 블록에 고정 ID

배지가 인용 핸들이다 — "PAY-001-02"는 언제나 특정 블록 하나를 가리킨다. 검토 의견이나 감사 기록이 페이지 속 상자 위치를 설명하는 대신 ID로 바로 지목한다.

캔버스에는 최소한만

  • ID 배지, 이름, 짧은 흐름 한 줄
  • 입력·출력·제약은 캔버스 밖에
  • 대신 data-block-* 속성에 기록
  • 기존 노드 그대로, 새 SVG 문법 없음

요청 시 레지스트리 내보내기

모든 블록의 모든 속성을 요청 시 JSON 사이드카로 내보낸다. 다이어그램에서 매번 다시 생성하며, 따로 손으로 관리하지 않는다.
