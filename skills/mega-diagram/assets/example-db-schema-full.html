쇼핑몰 주문·결제 스키마 · public + billing

결제(체크아웃)를 뒷받침하는 물리 스키마. 테이블 5개, 실제 SQL 타입, 박스가 아닌 컬럼 단위로 연결한 외래 키. 점선 그룹은 기본 스키마가 아닌 `billing` 스키마 표시.

파괴적 관계

주문 삭제 시 연쇄 삭제

이 스키마의 유일한 `ON DELETE CASCADE`는 `order_items.order_id`. 주문을 지우면 주문 항목도 함께 삭제. 나머지 외래 키는 모두 `RESTRICT`.

박스 간이 아닌 컬럼 간 연결

  • 모든 외래 키는 양 끝 모두 특정 행에 고정
  • 행 높이 24px 고정으로 연결 위치 예측 가능
  • 연결선의 핵심 정보는 `ON DELETE` 레이블

하위 시스템 범위로 한정

`products`는 모든 컬럼을 나열하지 않고 `외 컬럼 3개` 행으로 축약. 데이터베이스 전체의 `\d+`가 아닌 결제 영역만 표시.
