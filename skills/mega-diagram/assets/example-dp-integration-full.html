공공 데이터 플랫폼 연계 구성도

민원·통계·센서 데이터 3종이 원천 저장소에 적재되고, 통합 질의 엔진이 대시보드·노트북·개방 API 3개 채널에 제공. 인증과 감사 로그는 플랫폼 전 계층에 공통 적용.

THE HEADLINE

저장과 질의가 플랫폼의 핵심

원천 저장소는 적재를, 통합 질의 엔진은 통제된 조회를 담당. 연계 프로토콜은 그대로 표기.

연계 방식 명시

  • 민원 시스템: REST 연계
  • 지자체 통계: 일 단위 CSV 파일
  • 활용 채널: JDBC·커널·HTTPS

공통 서비스는 계층 단위 적용

통합 인증과 감사 로그는 개별 구성 요소가 아닌 플랫폼 경계에서 일괄 적용.
