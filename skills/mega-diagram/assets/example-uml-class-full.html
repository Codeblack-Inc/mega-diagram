주문·결제 도메인 · 클래스 다이어그램

PaymentMethod는 두 결제 수단이 실체화하는 계약. Order는 주문 항목을 합성하고 고객을 참조. PaymentService는 구체 결제 수단이 아닌 인터페이스에만 의존.

핵심 요약

계약은 PaymentMethod

Card와 BankTransfer 모두 인터페이스를 실체화(빈 삼각형 점선). PaymentService는 항상 인터페이스와만 통신하고 구체 결제 수단은 직접 호출하지 않음.

합성 = 전체와 생명주기 공유

  • OrderLine은 Order 밖에서 존재하지 않음
  • 채운 마름모는 소유자인 Order 쪽에 표시
  • Order는 Customer를 참조만 할 뿐 생명주기 공유 없음

의도적으로 생략한 요소

getter·setter와 전체 속성 목록은 생략. 표시한 멤버는 모두 이 다이어그램의 논지에 필요한 항목만 선별.
