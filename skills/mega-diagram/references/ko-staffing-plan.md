# 인력 투입 계획 (Staffing plan · M/M)

**쓰는 곳:** SI 제안서·용역 사업계획서의 **인력 투입 계획표**. 행은 투입 역할(PM, 분석, 설계, 개발, 품질, 인프라…), 열은 사업 기간의 월(보통 12개월). 막대가 투입 기간과 투입률을, 오른쪽 열이 역할별 M/M을, 맨 아래 행이 월별 합계와 총 M/M을 보여 준다. 평가위원은 이 표로 투입 인력의 규모·시점·피크를 확인한다.

**쓰지 않는 곳:**

- 과업(무엇을)의 일정 → **세부 추진 일정표** ([ko-schedule-table.md](ko-schedule-table.md)) 또는 **Gantt** ([type-gantt.md](type-gantt.md)). 이 표의 행은 과업이 아니라 사람(역할)이다.
- 조직의 보고 관계 → **조직도** ([type-org-chart.md](type-org-chart.md)) 또는 **추진 체계도** ([type-governance.md](type-governance.md)).
- 역할 × 월 투입률을 색 농도로만 보여 줘도 되는 대규모 표(역할 12개 이상) → **히트맵** ([type-heatmap.md](type-heatmap.md)).

**상속:** [type-gantt.md](type-gantt.md). 왼쪽 라벨 열 + 시간축, 연속 기간은 막대 하나, 초점 막대 1개(accent), 나머지는 `muted @ 0.15` + `muted` 테두리 규칙을 그대로 쓴다. 차이: 행이 사람이고, 행 끝에 합계 열과 표 끝에 합계 행이 붙는다. 한글 행 이름은 Gantt의 10~11px가 아니라 **12px 600**이다.

## Layout conventions

Canvas `viewBox="0 0 1000 504"` (역할 8개 기준).

1. **열:** 역할 라벨 x=32 폭 176 (이름 12px 600 x+12, 등급 12px 500 `muted` 오른쪽 정렬 x+164). 월 격자 x=208부터 12 × 56 = 672 (x=880까지). M/M 열 x=880, 폭 88, 값 오른쪽 정렬 x=956.
2. **머리 행:** y=24, 높이 40, `ink @ 0.05`, `rx=6`. `투입 인력`·`등급`·`1월`~`12월`(12px 500 `muted`, 월 중앙)·`M/M`. baseline y+25.
3. **역할 행:** y=64부터 pitch 40. 행 사이 `ink @ 0.08` 헤어라인, 월 경계 `ink @ 0.08` 세로선, M/M 열 앞 `ink @ 0.12` 세로선.
4. **막대:** 행 y+12, 높이 16, `rx=4`. x = 208 + 56 × (시작월 − 1) + 4, 폭 = 56 × 개월 − 8. 투입률이 바뀌면 막대를 나눈다.
   - 전담 100%: `muted @ 0.15` + `muted`.
   - 부분 투입 50%: `ink @ 0.03` + `muted` 점선 `4,3`, 막대 중앙에 Geist Mono 9px `50%`.
   - 동시 투입 2명: 막대 하나에 Mono 9px `×2`. 인원을 행으로 쪼개지 않는다.
5. **합계 행:** 마지막 역할 아래 y, 높이 40, `ink @ 0.05`. 월별 M/M 12px 500 중앙, 총 M/M 14px 600. **막대보다 먼저 그린다**(나중에 그린 큰 rect가 막대를 덮지 않도록).
6. **범례 줄:** 합계 행 아래 24px 헤어라인, baseline +28 — 전담 100%, 부분 50%, 최대 투입 역할, 동시 투입 인원.

## 계산 규칙

- 역할 M/M = Σ(개월 × 투입률 × 인원). 월 합계 = 그 달 투입률 합. **두 합의 총계가 같아야 한다** — 생성 스크립트에서 assert.
- 값은 소수 첫째 자리(`12.0`, `3.5`).

## 초점

accent 1개: **M/M이 가장 큰 역할**(보통 개발) — 막대 `accent-tint` + `accent`, 행 이름과 M/M 값도 `accent`. 피크 달을 따로 칠하지 않는다; 합계 행 숫자가 피크를 보여 준다.

## 한국어 표기

- 역할명 명사형 8자 이내(`아키텍처 설계`, `인프라·보안`). 두 역할을 묶을 때 `·`.
- 등급은 `특급·고급·중급·초급`. 이름 + 등급이 176px 안에 들어가야 한다(이름 ≤ 112px).
- 머리 `M/M`은 Latin 그대로. 월은 `1월`~`12월`; 사업이 해를 넘기면 `2026.11` 형식 Mono 9px.

## Complexity budget

- 역할 4~10행, 월 6~12열. 역할 한 행당 막대 3개 이하.
- accent 1개.

## Anti-patterns

- **사람 이름·실명.** 제안서 단계에서는 역할과 등급만.
- **M/M 열과 막대가 따로 노는 표.** 손으로 적은 합계는 틀린다. 계산해서 쓴다.
- **투입률을 막대 높이·색 농도로만 표시.** 50%는 점선 + 숫자로 밝힌다.
- **과업명을 막대 안에 쓰기.** 그건 일정표다.
- **12개월을 넘는 열을 좁혀 욱여넣기.** 분기 열로 묶거나 연도별로 나눈다.

## Checklist

- [ ] 역할 M/M 합 = 월 합계의 합 = 총 M/M인가?
- [ ] 부분 투입은 점선 + `50%`, 복수 인원은 `×N`인가?
- [ ] 합계 행을 막대보다 먼저 그렸는가(verify-geometry)?
- [ ] accent는 최대 투입 역할 하나인가? 한글 12px 이상인가?
