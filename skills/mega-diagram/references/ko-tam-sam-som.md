# 시장 규모 (TAM · SAM · SOM)

**쓰는 곳:** 사업계획서·투자 제안서·정부 지원사업 신청서의 "목표 시장" 절. 전체 시장(TAM)에서 자사 제품이 닿을 수 있는 유효 시장(SAM), 기간 안에 실제로 확보할 목표 시장(SOM)으로 좁혀 가는 추정을 한 장에 보인다. 숫자마다 산출 근거가 붙어 있어야 심사자가 추정을 따라갈 수 있다.

**Base type:** [type-nested.md](type-nested.md) (포함 관계, 바깥 = 넓은 범위) · [type-venn.md](type-venn.md) (원 도형과 원 안 라벨). 원은 포함만 뜻하고 겹침(교집합)은 없다.

## 쓰지 않는 곳

- **연도별 시장 성장**(2024→2029 CAGR): 막대나 선 그래프 — [type-bar.md](type-bar.md), [type-line.md](type-line.md).
- **세그먼트별 비중**(전자 42%, 자동차 31% …): 트리맵 — [type-treemap.md](type-treemap.md). 동심원은 부분의 합이 아니다.
- **두 시장이 일부만 겹침**: 벤 — [type-venn.md](type-venn.md).
- **근거 없는 숫자 셋**: 원을 그리지 말고 문장으로 쓴다. 산출 근거가 이 그림의 절반이다.

## Layout grammar

`0 0 1000 560` viewBox, 4px grid. 왼쪽 원 묶음, 오른쪽 근거 열, 맨 아래 출처 줄.

| 요소 | 값 |
|---|---|
| 원 중심 | `(288, 264)` |
| 반지름 | TAM 216 · SAM 144 · SOM 72 (띠 두께 72, 모두 4의 배수) |
| 원 안 라벨 | 띠 위쪽 `top + 28`에 태그(14px 600), `+20`에 규모(12px 500 `muted`), 가운데 정렬. SOM은 중심 `cy − 4` |
| 근거 열 | x = 584–960 (폭 376). 블록 기준선 y = 112 · 216 · 320 (간격 104) |
| 블록 | 1행: 태그(Geist Mono 9px) + 이름(14px 600) + 규모(14px 600, x = 960 오른쪽 정렬) · `+12` 헤어라인 · `+34` 산출식(12px 500 `ink`) · `+54` 범위 설명(12px 400 `muted`) |
| 지시선 | 블록 기준선 `− 4` 높이의 수평선, 0.8px. 시작점은 **자기 띠 안**의 점(r = 2.5), 끝은 x = 568 (근거 열 16px 앞). 화살촉 없음 |
| 출처 줄 | 헤어라인 y = 508, 텍스트 기준선 536: `출처`(12px 500) + 자료 목록(12px 400) |

- **지시선은 수평 직선이다.** 점과 블록이 같은 y에 있어 SKILL.md §6 규칙 1의 "같은 축" 예외에 해당한다. 점 위치는 `안쪽 반지름 < √(dx² + dy²) < 바깥 반지름`을 만족해야 한다 — 생성 스크립트에서 assert로 확인한다. 지시선이 바깥 원들의 테두리를 가로지르는 것은 괜찮다(원은 노드가 아니라 영역이다).
- **그리는 순서:** 원(바깥 → 안, SOM이 마지막) → 원 안 라벨 → 지시선 → 근거 블록 → 출처 줄.
- **범례 없음.** 강조색이 뜻하는 바(SOM)는 SOM 블록 자신이 말한다. 맨 아래 띠는 범례 대신 출처 줄이 차지한다.

## Treatments

| 역할 | Fill | Stroke |
|---|---|---|
| TAM | `ink @ 0.02` | `ink @ 0.30` |
| SAM | `ink @ 0.04` | `muted` |
| SOM (focal) | `accent-tint` | `accent` — 태그·규모·지시선도 `accent` |
| 근거 블록 | 없음 | 헤어라인 `rule` |

**Focal rule:** 강조는 SOM 하나(원과 그 블록이 한 요소). 자사가 공략할 범위이기 때문이다. TAM을 강조하면 "시장이 크다"만 남고 추정의 결론이 사라진다.

## Korean wording

- **태그는 영문 약어 그대로**(`TAM`, `SAM`, `SOM`) — 심사 양식이 이 약어를 쓴다. 이름은 명사형 `전체 시장` · `유효 시장` · `목표 시장`.
- **규모는 `억 원` 하나로.** `2조 4,000억 원`이 아니라 `24,000억 원` — 세 숫자를 같은 단위로 비교하게 한다. 예외는 산출식 안의 단가(`× 3,000만 원`)뿐이다. 단가는 규모가 아니라 곱하는 인자이므로 원래 단위로 쓴다.
- **산출식은 `수량 × 단가` 한 줄**(`중소 부품사 1만 2,000곳 × 3,000만 원`). SOM은 SAM에서 몇 %인지 먼저 쓴다(`SAM 사업장의 5%, 600곳 × 3,000만 원`).
- **범위 설명**은 무엇을 셌는지 한 줄(`전자·자동차 부품, 비전 검사 대상 공정`), 기간이 있으면 연도(`2029년까지 …`).
- **출처**는 기관명 + 조사명(연도), 쉼표로 나열. 자체 추정은 `자사 추정`이라고 밝힌다.
- **폭:** 근거 열 376px에 12px 한 줄 = 한글 약 26자. 넘으면 줄이지 두 줄로 나누지 않는다.

## Complexity budget

- 원 3개(TAM·SAM·SOM). 4단계(예: `서비스 가능 시장` 추가)가 필요하면 반지름을 216 · 160 · 104 · 48로 줄이고 근거 블록 간격을 88로 — 그 이상은 표로.
- 블록당 근거 2줄. 3줄이 필요하면 각주로 보낸다.
- 강조 1개.

## Anti-patterns

- **원 넓이를 값에 비례시키기.** 24,000 : 3,600 : 180이면 SOM은 점이 된다. 원은 포함 관계만 보이고 크기는 숫자가 말한다 — 반지름은 등간격.
- **숫자 없이 원만** 있거나, 산출 근거 없이 숫자만 있는 그림.
- **근거를 원 안에 쓰기.** 띠 72px에 문장이 들어가지 않고, 지시선이 없어지면 어느 원 설명인지 흐려진다.
- **사선 지시선.** 점과 블록의 y를 맞추면 수평선으로 충분하다.
- **세 원에 각기 다른 색.** 계층은 명도(0.02 → 0.04 → tint)로 보인다.
- **단위 섞기**(`2.4조`, `3,600억`, `18B`).
- **그림 번호·캡션을 SVG 안에**(`[그림 2] 시장 규모`) — 문서 도구가 붙인다([mega.md](mega.md)).

## Pre-output checklist

- [ ] 반지름 등간격, 중심·반지름 모두 4의 배수?
- [ ] 세 규모가 모두 `억 원`, 천 단위 쉼표?
- [ ] 블록마다 산출식(수량 × 단가)과 범위 한 줄?
- [ ] 지시선 시작점이 자기 띠 안에 있고, 수평이며, 화살촉이 없는가?
- [ ] 강조는 SOM 하나?
- [ ] 출처 줄이 맨 아래에 있고 자체 추정을 밝혔는가?
- [ ] 한글 12px 이상, 글자 크기는 9(mono) · 12 · 14만?
- [ ] light · dark · full 라벨이 같은가?
