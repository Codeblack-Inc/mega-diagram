# 경쟁사 비교표 (Competitor matrix)

**쓰는 곳:** 사업계획서·IR 자료·제안서의 "경쟁 현황" 절. 자사와 경쟁 대안 3–4개를 같은 기준 5–6개로 나란히 놓고, 기준마다 ● / ◐ / ○ (Harvey ball)로 평가한 뒤 맨 아래 종합 점수로 닫는다. 심사자는 표 한 장으로 "어디서 이기고 어디서 지는지"를 읽는다.

**Base type:** [type-dp-security-matrix.md](type-dp-security-matrix.md) — 행 × 열 격자, 칸마다 닫힌 어휘의 값, 초점 하나. 차이는 세 가지: 열이 역할이 아니라 경쟁사, 칸 값이 글자가 아니라 SVG로 그린 Harvey ball, 맨 아래 합계 행.

## 쓰지 않는 곳

- **두 축으로 포지셔닝**(가격 × 기능): 사분면 — [type-quadrant.md](type-quadrant.md).
- **정량 지표 비교**(검출률 97.2% vs 99.1%): 막대나 표. 숫자를 ◐로 뭉개지 않는다 — [type-bar.md](type-bar.md).
- **경쟁사 7곳 이상** 또는 **기준 8개 이상**: 표 도구로. 도식이 아니라 부록 표다.
- **여러 축의 모양 비교**(자사 vs 1곳): 레이더 — [type-radar.md](type-radar.md).

## Layout grammar

`0 0 1000 H` viewBox (6개 기준이면 H = 472), 4px grid.

| 요소 | 값 |
|---|---|
| 기준 열 | x = 40, 폭 192. 기준명(12px 600) x + 16, 부연(12px 400 `soft`) 오른쪽 정렬 x + 184 |
| 경쟁사 열 | 5열 × 폭 128, 간격 16: x = 256 + 144k, 중심 x + 64. 4열이면 폭 164, 간격 16 |
| 머리 행 | y = 40, 높이 56. 구분(12px 500 `soft`) 기준선 +22, 이름(14px 600) +42, 가운데 정렬 |
| 본문 행 | y = 112부터 높이 40. 행 사이 `rule` 헤어라인 0.8, 머리 행 아래는 `rule-solid` 1 |
| Harvey ball | 행 중심, r = 8. ○ = `paper` 채움 + `ink` 테두리 1, ◐ = ○ + 오른쪽 반원 `M cx,cy−8 A 8,8 0 0,1 cx,cy+8 Z`, ● = `ink` 채운 원 |
| 합계 행 | 본문 끝(y = 352) `rule-solid` 1 위, 높이 48. `종합 점수`(14px 600) + `6점 만점`, 점수 16px 600 |
| 자사 열 띠 | 머리 행 top부터 합계 행 bottom까지 한 rect, `rx=6`. **가장 먼저 그린다** — 헤어라인과 공이 그 위에 올라온다 |
| 범례 | 헤어라인 = 합계 bottom + 16, 항목 기준선 +44: ● ◐ ○ 각 점수 · 자사 견본 · 오른쪽 끝 조사 출처(12px 400 `soft`) |

- **공은 글리프가 아니라 도형이다.** `●◐○` 문자는 글꼴마다 크기와 기준선이 달라 열이 흔들린다. 범례의 공도 같은 함수로 그린다.
- **그리는 순서:** 자사 열 띠 → 머리 행 → 행 헤어라인·기준명 → 공 → 합계 → 범례.
- 연결선 없음.

## Treatments

| 역할 | Fill | Stroke / 글자 |
|---|---|---|
| 자사 열 (focal) | `accent-tint` | `accent` 1, 구분 캡션 `accent` |
| 자사 종합 점수 | — | `accent` 16px 600 |
| 경쟁사 열 | 없음 | 헤어라인만 |
| Harvey ball | `ink` / `paper` | `ink` 1 — 자사 열도 같은 `ink`. 공을 파랗게 칠하지 않는다 |

**Focal rule:** 강조는 자사 열 하나(띠 + 종합 점수가 한 요소). 경쟁사의 강점 칸을 따로 칠하지 않는다 — 공이 이미 말한다.

## Korean wording

- **구분 캡션**(열 위): 경쟁사의 성격 `글로벌 장비사` · `대기업 SI` · `스타트업` · `현행 방식`. 자사는 `자사`.
- **이름**: 실명 대신 `K사`, `H정보통신` 같은 가명이 기본(공개 문서). 14px 한 줄 ≤ 7자.
- **현행 방식을 열에 넣는다**(`육안 검사`, `엑셀 수작업`). 가장 강한 경쟁은 흔히 "아무것도 안 사는 것"이다.
- **기준명** 명사형 ≤ 7자(`도입 비용`, `소량 샘플 학습`), **부연**은 측정 조건 ≤ 5자(`라인당`, `50장 기준`, `24시간 내`).
- **방향을 통일**: ●는 언제나 "자사 고객에게 유리"다. `도입 비용 ●`는 비용이 **낮다**는 뜻 — 기준명을 `저비용`으로 바꾸기보다 범례를 `우수`로 쓴다.
- **점수**는 `5.5` 한 자리 소수, 만점은 기준 열에(`6점 만점`).

## Complexity budget

- 경쟁사 열 ≤ 5(자사 포함), 기준 행 ≤ 6, 평가 단계 3(●◐○). 4–5단계 공(¼, ¾)은 인쇄에서 구분되지 않는다.
- 강조 1개.
- 자사가 모든 칸에서 ●이면 표를 믿지 않는다. 약점 한두 칸을 남기고 요약 카드에서 대응을 적는다.

## Anti-patterns

- **텍스트 글리프(●◐○)나 이모지(✅❌)로 칸 채우기.**
- **자사 칸의 공만 파랑**: 강조가 30개로 늘어난다.
- **가중치를 숨긴 종합 점수.** 가중치를 쓰면 기준명 옆에 `×2`로 밝힌다. 없으면 요약 카드에 "가중치 없음".
- **칸마다 박스.** 행 헤어라인으로 충분하다. 30개 박스는 자사 열 띠를 묻어 버린다.
- **출처 없는 평가.** 범례 줄 오른쪽에 조사 시점과 방법을 적는다.
- **그림 번호·캡션을 SVG 안에** — [mega.md](mega.md).

## Pre-output checklist

- [ ] 열 x = 256 + 144k, 행 y = 112 + 40i, 모두 4의 배수?
- [ ] 공이 r = 8 SVG 도형이고 범례도 같은 도형?
- [ ] ● 방향(자사 고객에게 유리)이 모든 기준에서 같은가?
- [ ] 현행 방식(대체 수단) 열이 있는가?
- [ ] 합계 = ● 1 · ◐ 0.5 · ○ 0의 합과 일치(생성 스크립트에서 계산)?
- [ ] 강조는 자사 열 하나, 공은 모두 `ink`?
- [ ] 한글 12px 이상, 글자 크기는 12 · 14 · 16만?
- [ ] light · dark · full 라벨이 같은가?
