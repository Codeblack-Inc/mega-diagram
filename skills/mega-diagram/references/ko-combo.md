# 콤보 차트 (Combo · 막대 + 선, 이중 축)

**쓰는 곳:** **크기(금액)와 비율(증가율)** 을 같은 기간 축에 함께 놓아야 할 때 — `매출액과 전년 대비 증가율`, `예산과 집행률`, `민원 건수와 처리율`. 사업계획서·IR 자료에서 가장 흔한 실적 도표다. 막대는 왼쪽 축(금액), 선은 오른쪽 축(%)으로 읽는다.

**쓰지 않는 곳:**

- 두 값의 단위가 같다 → **묶은 막대** 또는 **선 여러 개** ([type-line.md](type-line.md)). 이중 축은 단위가 다를 때만 쓴다.
- 증가율이 금액에서 바로 계산되고 독자가 금액만 본다 → **막대 + 값 라벨**. 선이 없으면 축도 하나다.
- 두 계열의 상관을 주장하고 싶다 → **산점도** ([type-scatter.md](type-scatter.md)). 이중 축의 교차점은 축 범위를 고른 결과일 뿐 의미가 없다.

**상속:** 막대는 [type-bar.md](type-bar.md), 선은 [type-line.md](type-line.md)의 규칙(폴리라인, 스플라인 금지, 점은 초점 계열만 채움)을 그대로 따른다.

## Layout conventions

Canvas `viewBox="0 0 1000 488"`.

1. **플롯:** x0=96, pitch 128, 막대 폭 72, 첫 막대 x0+28. 6개 기간이면 x1=864. 기준선 y=376, 플롯 높이 320.
2. **두 축은 모두 0에서 시작하고 격자를 공유한다.** 왼쪽 0~400 억 원(0.8px/억 원), 오른쪽 0~40%(8px/%). 같은 5개 격자선(`ink @ 0.08`)에 두 눈금이 걸리도록 범위를 고른다: `100억 원 = 10%`. 왼쪽 눈금 x0−8 `end`, 오른쪽 눈금 x1+8 `start`, 모두 Geist Mono 9px `muted`. y축선은 양쪽(x0, x1)에 `ink @ 0.25` 1px.
3. **축 제목 = 계열 열쇠.** 좌상단 (32, 36)에 막대 스와치(12×8) + `매출액(억 원) · 왼쪽 축`, 우상단에 `증가율(%) · 오른쪽 축` + 선 스와치(24px, 1.8). 축 제목만 보고 어느 모양이 어느 축인지 알 수 있어야 한다.
4. **막대:** `paper` 마스크 + `muted @ 0.15` 채움 + `muted` 1px. 값 라벨 `289억 원`은 **막대 안 아래쪽**(baseline 기준선−12) 12px 500 — 막대 위에 두면 선과 부딪힌다. 라벨 폭 + 8 ≤ 막대 폭(assert).
5. **선:** 막대 중심 x를 잇는 `<polyline>` `ink` 1.8px, `stroke-linejoin="round"`. 점 r=4 `paper` 채움 + `ink` 1.5px. 증가율은 스크립트가 매출에서 계산한다(첫 해는 전년 값을 데이터로 두고 범례 줄에 밝힌다).
6. **선 값 라벨:** Geist Mono 9px 600, 12px 높이 `paper` 마스크. 위치는 인접 선분이 비워 둔 쪽: 봉우리 → 위(−12), 골 → 아래(+20), 오르는 점 → 오른쪽 아래(x+10, +16), 내려가는 점 → 오른쪽 위(x+10, −8). 막대 안 값 라벨과 24px 이상 떨어져야 한다(assert).
7. **x축 라벨:** 12px 600, 기준선 아래 20px.
8. **범례 줄:** y=424 헤어라인, y=442 `LEGEND`, 항목 baseline 464 — 막대(왼쪽 축), 선(오른쪽 축), 초점 연도, 오른쪽 끝에 계산 기준(`2021 증가율은 2020 매출 96억 원 기준`).

## 초점

accent 요소는 최대 2개이며 **같은 연도**를 가리킨다: 그 해 막대(`accent @ 0.12` + `accent` 테두리, 값 라벨 `accent` 600)와 선 위의 같은 해 점(r=5 `accent` 채움, 값 라벨 `accent`). 다른 해에 accent를 나누지 않는다.

## 한국어 표기

- 축 제목은 `이름(단위) · 왼쪽 축` 꼴. `좌축/우축`보다 `왼쪽 축/오른쪽 축`이 보고서 독자에게 분명하다.
- 막대 값은 `289억 원`, 선 값은 `35.0%`(소수 첫째 자리 통일). 음수 증가율은 `−4.2%`.
- 계산 기준·추정치 여부는 범례 줄 오른쪽 끝 한 줄로.

## Complexity budget

- 기간 4~8개, 막대 계열 1개 + 선 계열 1개. 막대를 묶거나 선을 늘리면 이중 축이 읽히지 않는다 — 두 장으로 나눈다.
- accent 2개(같은 연도의 막대와 점).

## Anti-patterns

- **한쪽 축만 0에서 시작하거나, 선을 막대 위로 띄우려고 오른쪽 축을 음수부터 시작하기.** 두 축 모두 0부터, 격자 공유.
- **축 제목 없는 오른쪽 눈금.** 어느 축이 무엇인지 모르면 선의 높이는 무의미하다.
- **막대 위 값 라벨** — 선·점과 겹친다. 막대 안 아래쪽에.
- **선과 막대가 만나는 지점에 의미 부여**(“증가율이 매출을 넘어섰다”). 단위가 다르다.
- **스플라인 곡선, 모든 점을 accent로.**

## Checklist

- [ ] 두 계열의 단위가 다르고, 두 축 모두 0에서 시작하며 격자를 공유하는가?
- [ ] 좌상단·우상단 축 제목에 계열 스와치가 붙어 있는가?
- [ ] 증가율을 매출 데이터에서 계산했고, 첫 해 기준값을 밝혔는가?
- [ ] 막대 값은 막대 안, 선 값은 마스크를 깔고 인접 선분을 피했는가?
- [ ] accent는 같은 연도의 막대와 점 두 개뿐인가? 한글 12px 이상인가?
