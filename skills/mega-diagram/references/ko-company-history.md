# 연혁 (Company history · 연도별 이력)

**쓰는 곳:** 회사소개서·IR 자료·입찰 제안서의 **회사 연혁**, 기관의 **주요 연혁**. 세로 줄기(spine)에 연도를 위에서 아래로(최신이 위) 놓고, 연도마다 2~3건의 이력을 월 순서대로 가로로 적는다. 이력마다 구분 태그(설립·인증·특허·출시·투자·수상·성장)와 `YYYY.MM` 날짜를 붙인다. 한 해를 전환점으로 강조한다.

**쓰지 않는 곳:**

- 날짜 간격 자체가 의미 있다(몇 달 만에 무엇이 일어났나) → **타임라인** ([type-timeline.md](type-timeline.md)). 연혁은 연도 행이 같은 높이라 간격을 말하지 않는다.
- 앞으로의 계획 → **로드맵** ([type-roadmap.md](type-roadmap.md)). 연혁은 지난 일만.
- 이력이 20건 이상인 전체 목록 → 표. 그림은 주요 이력만.

**상속:** [type-timeline.md](type-timeline.md). 한 줄 축, 점 표지, 초점 1~2개, Mono 날짜 규칙을 따른다. 차이: 축이 세로이고 **연도 단위 행**(같은 높이)이다 — 비례 간격 규칙은 연도 순서로 대체되므로 범례나 본문에 "최신 연도가 위"를 밝힌다.

## Layout conventions

Canvas `viewBox="0 0 1000 552"` (8개 연도 기준).

1. **연도 행:** y=24부터 pitch 56, 최신 연도가 위. 연도 16px 600 오른쪽 정렬 x=112, baseline row+34.
2. **줄기:** x=136, `muted` 1.2px, 첫 점에서 마지막 점까지. 점은 row+28에 r=4 `ink`.
3. **이력 칸:** x=168 / 432 / 696, 폭 264 (연도당 최대 3건, 월 순서로 왼쪽부터).
   - 구분 태그: rect `rx=2`, 높이 12, `ink @ 0.40` 0.8px 테두리, Geist Mono 7px tracked 0.08em(`INVEST`, `CERT`). 폭 = 글자 수 × 5 + 12, 4의 배수로 올림. y=row+13.
   - 날짜: 태그 오른쪽 8px, Geist Mono 9px `muted` `2023.03`, baseline row+22.
   - 이력명: 12px 600 `ink` x, baseline row+42. 240px 안.
4. **행 구분선:** 이력 영역(x=168~960)에만 `ink @ 0.08` 헤어라인. 초점 띠와 닿는 줄은 뺀다.
5. **초점 연도 띠:** 행 y+4, 높이 48, x=32 전폭 936, `accent-tint` + `accent` 1px, `rx=6`. 줄기보다 먼저 그려 줄기가 띠 위를 지나가게 한다.
6. **범례 줄:** 마지막 행 아래 24px 헤어라인, baseline +28 — 연도(점), 전환점 연도(띠), 이력 구분(태그 → 한글 대응 `설립·인증·특허·출시·투자·수상·성장`).

## 태그 어휘 (Latin, 고정)

`FOUND` 설립 · `CERT` 인증 · `IP` 특허 · `LAUNCH` 출시 · `INVEST` 투자 · `AWARD` 수상 · `GROWTH` 성장(매출·고객 돌파). 태그는 7px Mono in-box tag라 한글을 쓰지 않는다; 대응표는 범례에 한 번 적는다.

## 초점

accent는 한 연도에만, 2요소: 그 연도의 띠(`accent-tint` + `accent`, 연도 숫자 `accent` 포함)와 줄기 위 점(r=6, `accent`). 이력 텍스트와 태그는 중립.

## 한국어 표기

- 이력명 명사형 16자 이내(`시리즈 A 투자 유치 80억 원`, `기업부설연구소 설립`). 금액은 `억 원`, 인증명은 공식 명칭.
- 제품명은 작은따옴표 `‘다온 WMS’`.
- 날짜 `YYYY.MM`, 같은 달 이력 두 건이면 한 칸에 합친다.

## Complexity budget

- 연도 5~8개, 연도당 이력 1~3건(총 24건 이하), 초점 연도 1개.
- 8년을 넘으면 초기 연도를 `2015~2018` 한 행으로 묶는다.

## Anti-patterns

- **모든 이력 나열.** 연도당 3건을 넘기면 표로 뺀다.
- **태그마다 색.** 구분은 글자로; 색은 전환점 하나.
- **오래된 연도를 위에** 두고 최신을 아래에 — 회사소개서 관행은 최신이 위다. 반대로 쓸 땐 범례에 밝힌다.
- **연도 사이 간격을 경과 기간처럼 보이게 늘이기.** 연혁은 같은 행 높이; 간격이 의미 있으면 타임라인.
- **이력명에 문장·서술어**(`인증을 획득하였음`).

## Checklist

- [ ] 연도가 최신순이고 연도 안 이력이 월 순서인가?
- [ ] 모든 이력에 태그와 `YYYY.MM`이 있는가?
- [ ] 초점 연도는 하나이고 띠를 줄기보다 먼저 그렸는가?
- [ ] 이력명이 240px 안에 들어가는가? 한글 12px 이상인가?
