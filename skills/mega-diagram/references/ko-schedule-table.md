# 세부 추진 일정표 (Schedule table · 추진 내용 × 월)

**쓰는 곳:** 사업계획서·R&D 과제 제안서·용역 착수계 어디에나 들어가는 **세부 추진 일정** 표. 행은 단계로 묶은 추진 내용, 열은 1~12월, 수행하는 달의 칸을 ■로 채우고 보고회·검수 같은 관문은 ★로 찍는다. 오른쪽 열에 추진 내용별 산출물을 적는다. HWP 표로 그리던 것을 같은 문법으로 옮긴 그림이다.

**쓰지 않는 곳:**

- 주·일 단위로 겹침과 선후 관계가 중요하다 → **Gantt** ([type-gantt.md](type-gantt.md)).
- 여러 해에 걸친 단계별 과제·성과 → **로드맵** ([type-roadmap.md](type-roadmap.md)). 일정표는 한 해, 월 단위다.
- 사람의 투입 기간 → **인력 투입 계획** ([ko-staffing-plan.md](ko-staffing-plan.md)).
- 날짜가 몇 개뿐이다 → **타임라인** ([type-timeline.md](type-timeline.md)).

**상속:** [type-gantt.md](type-gantt.md). 단계 묶음(phase grouping), 월 축, 초점 1개 규칙을 따른다. 차이: 연속 막대 대신 **월 칸을 하나씩 채우고**(보고서 관행), 산출물 열이 붙으며, 단계는 병합 셀로 표시한다.

## Layout conventions

Canvas `viewBox="0 0 1000 480"` (추진 내용 10행 기준).

1. **열:** 단계 x=32 폭 80 / 추진 내용 x=112 폭 176 / 월 x=288부터 12 × 44 = 528 (x=816까지) / 산출물 x=816 폭 152 (x=968까지).
2. **머리:** y=24, 높이 56, `ink @ 0.05`. `단계`·`추진 내용`·`산출물` 12px 600 baseline y+33. 월 영역은 두 줄 — 위 `2026년 추진 일정` 12px 600 중앙 baseline y+22, `ink @ 0.12` 가로줄 y+30, 아래 `1월`~`12월` 12px 500 `muted` baseline y+47.
3. **표 테두리:** 머리 위부터 마지막 행까지 한 rect, `ink @ 0.30`, `rx=6`, 채움 없음. 열 경계 `ink @ 0.12`, 월 경계 `ink @ 0.06`.
4. **행:** y=80부터 pitch 32. 추진 내용 12px 500 x=124 baseline row+21; 산출물 12px 500 `muted` x=828. 같은 단계 안 행 사이 `ink @ 0.08`, **단계 경계는 `ink @ 0.30` 1px** 전폭.
5. **단계 병합 셀:** 묶음 높이 중앙에 `N단계` 12px 600, 그 아래 18px에 단계명 12px 500 `muted`.
6. **■ 수행 월:** 칸 안 x+6, y+8, 32×16, `rx=2`, `muted` 실색. 달마다 칸 하나 — 연속 막대로 잇지 않는다.
7. **★ 관문:** 10꼭짓점 별(외반경 8, 내반경 3.4)을 칸 중앙에, 그 달의 ■ 대신. `ink` 채움. 좌표는 계산값이라 격자 밖이어도 된다. **글리프 `★`·`■`는 쓰지 않는다**(폰트마다 모양·폭이 다르다).
8. **범례 줄:** 표 아래 24px 헤어라인, baseline +28 — 수행 월, 보고회, 핵심 관문.

그리는 순서: 머리 → 테두리·열선 → 행 텍스트·■ → ★ → 범례.

## 초점

accent 1개: **일정 전체가 걸린 관문** 하나(보통 중간 보고) — 그 ★을 `accent`로, 해당 추진 내용 이름을 `accent` 600으로. ■ 칸과 단계 셀은 칠하지 않는다.

## 한국어 표기

- 추진 내용 명사형 10자 이내(`관측 데이터 구축`, `성능 평가·보완`) — 152px 안.
- 단계명 5자 이내(`착수·분석`, `시험·확산`) — 64px 안.
- 산출물은 문서·결과물 이름(`요구사항 정의서`, `예측 모델 v1.0`), 추진 내용마다 하나.
- 해를 넘기면 머리 위 줄을 `2026년 | 2027년`으로 나누고 월은 그대로 `1월`.

## Complexity budget

- 단계 3~5개, 추진 내용 12행 이하, 관문 ★ 4개 이하, accent 1개.
- 12행을 넘으면 단계별 상세 일정표로 나눈다.

## Anti-patterns

- **■를 연속 막대로 그리기.** 그건 Gantt다. 이 표의 독자는 "몇 월에 하는가"를 칸으로 센다.
- **★을 텍스트 글리프로.** 렌더링이 흔들린다. polygon으로 그린다.
- **산출물 열을 빼기.** 평가위원의 점검 목록이 사라진다.
- **단계마다 다른 색.** 단계는 굵은 가로줄과 병합 셀로 충분하다.
- **월 칸 안에 글자 쓰기.** 44px 칸에 한글은 들어가지 않는다. 설명은 추진 내용·산출물 열로.

## Checklist

- [ ] 모든 ■·★이 추진 내용의 실제 수행 월과 맞는가?
- [ ] 단계 경계가 `ink @ 0.30`, 행 경계가 `ink @ 0.08`인가?
- [ ] ★은 polygon이고 accent ★은 하나뿐인가?
- [ ] 추진 내용·산출물이 칸 폭 안에 들어가는가(폭 예산)?
