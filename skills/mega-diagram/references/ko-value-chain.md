# 가치사슬 (Value chain)

**쓰는 곳:** 사업계획서·경영 전략 보고서의 "내부 역량 분석" 절. Porter의 가치사슬 — 위에 **지원 활동** 네 줄(기업 인프라·인적 자원 관리·기술 개발·조달), 아래에 **본원 활동** 다섯 단계(구매·운영·출고 물류·마케팅·판매·서비스)가 왼쪽에서 오른쪽으로 이어지고, 오른쪽 끝 **이윤** 화살촉으로 닫힌다. 자사가 이윤을 만드는 강점 1–2곳을 강조한다.

**Base type:** [type-layers.md](type-layers.md) — 같은 x·같은 폭의 가로 띠, 왼쪽 여백의 층 이름, 초점 층 하나. 가치사슬은 여기에 셰브런 한 줄과 이윤 쐐기를 더한다.

## 쓰지 않는 곳

- **실제 업무 절차**(누가 어떤 순서로 처리): 프로세스·스윔레인 — [type-process.md](type-process.md), [type-swimlane.md](type-swimlane.md).
- **산업 전체의 가치 흐름**(원자재사 → 제조사 → 유통 → 고객): 기업 간 가치 사슬은 프로세스 또는 생키.
- **조직 구조**: 조직도 — [type-org-chart.md](type-org-chart.md).
- **활동별 원가 비중이 요점**: 막대나 트리맵. 가치사슬 칸 폭은 같다.

## Layout grammar

`0 0 1000 488` viewBox, 4px grid. 블록 x = 120–876, 이윤 쐐기 x = 880–960.

| 요소 | 값 |
|---|---|
| 층 이름 (왼쪽 여백) | `지원 활동` x = 40, y = 152 · `본원 활동` x = 40, y = 344 (12px 500 `muted`) |
| 지원 활동 줄 | 4줄 × 높이 48, 간격 8: y = 40 · 96 · 152 · 208, 폭 756, `rx=6`. 이름 14px 600 x + 16, 내용 12px x + 168 |
| 본원 활동 셰브런 | y = 280, 높이 120. 간격(pitch) 152, 몸통 폭 148, 꼭지 16. 첫 칸은 왼쪽 홈 없음, 마지막 칸은 오른쪽이 평평(x = 876) |
| 셰브런 안 | 이름 14px 600 y + 36, 짧은 구분선 ±40 at y + 52, 설명 두 줄 12px 400 `muted` y + 76 · y + 96, 가운데 정렬 |
| 이윤 쐐기 | `polygon 880,40 916,40 960,220 916,400 880,400` — 지원·본원 두 블록 전체 높이. `이윤`(14px 600) y = 216, 비율(16px 600) y = 240 |
| 범례 | 헤어라인 y = 432, 기준선 464 |

- **연결선 없음.** 셰브런의 꼭지가 흐름 방향이다. 셰브런 사이 4px 틈은 꼭지 변과 홈 변이 평행하게 유지되도록 pitch − 몸통 폭 = 4.
- **지원 활동은 전폭.** 한 지원 활동이 모든 본원 활동을 떠받치므로 셰브런 칸에 맞춰 자르지 않는다.
- **이윤 쐐기는 두 블록을 모두 덮는다** — 이윤은 본원 활동만의 결과가 아니다.
- **그리는 순서:** 층 이름 → 이윤 쐐기 → 지원 활동 줄 → 셰브런 → 범례.

## Treatments

| 역할 | Fill | Stroke |
|---|---|---|
| 지원 활동 | `ink @ 0.03` | `ink @ 0.30` (external) |
| 본원 활동 셰브런 | `backend` (흰색) | `ink` (backend) |
| 자사 강점 (focal, ≤ 2) | `accent-tint` | `accent`, 이름도 `accent`. 지원 줄이면 내용을 `ink` 500으로 |
| 이윤 쐐기 | `ink @ 0.05` | `muted` (store) |

**Focal rule:** 강조 ≤ 2, 보통 지원 활동 하나 + 본원 활동 하나(예: `기술 개발` + `서비스`). 둘이 서로 이어질 때 가장 설득력 있다 — 기술이 만든 차별점이 어느 고객 접점에서 이윤이 되는지. 약점은 칠하지 않고 요약 카드에 적는다.

## Korean wording

- **활동 이름은 표준 용어**: 지원 `기업 인프라` · `인적 자원 관리` · `기술 개발` · `조달`, 본원 `구매`(=구매 물류) · `운영` · `출고 물류` · `마케팅·판매` · `서비스`. 업종에 맞게 바꿀 수 있지만 다섯 칸 순서는 유지한다.
- **지원 활동 내용**: 한 줄, 항목을 ` · `로 나열, 숫자 포함(`비전 AI 연구 인력 14명 · 현장 엔지니어 22명`). 폭 692px ≈ 12px 한글 45자.
- **셰브런 설명**: 두 줄, 줄당 ≤ 9자(몸통 148 − 꼭지 16 − 여백 16 = 116px). `현장 설치 2일`, `월 1회 재학습`.
- **이윤**: `이윤` + 비율 하나(`18%`). 기준(목표 연도, 영업이익률)은 범례 항목에 적는다: `이윤(2028년 영업이익률 목표)`.

## Complexity budget

- 지원 4줄 · 본원 5칸 고정(Porter 원형). 본원을 6칸으로 늘리면 pitch 124 · 몸통 120 · 설명 ≤ 7자.
- 셰브런당 설명 2줄, 지원 줄당 1줄.
- 강조 ≤ 2.

## Anti-patterns

- **셰브런 사이 화살표**: 꼭지가 이미 방향이다.
- **활동마다 다른 색**, **강점 셋 이상 강조**.
- **지원 활동을 셰브런 칸마다 잘라 그리기**: 격자 표가 되고 "전 활동을 떠받친다"는 뜻이 사라진다.
- **이윤을 본원 블록 옆에만**: 쐐기는 두 블록 높이 전체.
- **설명 없는 빈 셰브런**: 이름만 있으면 교과서 그림이다. 자사의 사실(숫자)을 넣는다.
- **그림 번호·캡션을 SVG 안에** — [mega.md](mega.md).

## Pre-output checklist

- [ ] 지원 줄 y = 40 + 56i, 셰브런 x = 120 + 152k, 모두 4의 배수?
- [ ] 첫 셰브런은 홈 없음, 마지막은 오른쪽 평평, 쐐기와 4px 틈?
- [ ] 이윤 쐐기가 y = 40–400 전체를 덮는가?
- [ ] 셰브런 설명 줄당 ≤ 9자, 지원 내용 한 줄?
- [ ] 강조 ≤ 2, 범례에 `자사 강점`?
- [ ] 연결선 0개?
- [ ] 한글 12px 이상, 글자 크기 12 · 14 · 16만?
- [ ] light · dark · full 라벨이 같은가?
