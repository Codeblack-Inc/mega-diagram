# 추진 절차 (Procedure steps · 단계 × 주체·내용·기간)

**쓰는 곳:** 공모 사업 공고문, 지원사업 안내서, 사업계획서의 **추진 절차** 그림. 5~6개 단계를 셰브론으로 한 줄에 놓고(`공고 → 접수 → 평가 → 선정 → 협약 → 수행`), 단계마다 아래 칸에 **주체**, **주요 내용** 불릿, **기간**을 적는다. 신청자가 "누가, 무엇을, 언제까지"를 한 열씩 읽게 한다.

**쓰지 않는 곳:**

- 분기·반복·예외가 있는 흐름 → **순서도** ([type-flowchart.md](type-flowchart.md)). 추진 절차는 곧게 이어지는 한 줄이다.
- 주체 사이 주고받는 흐름이 핵심이다 → **스윔레인** ([type-swimlane.md](type-swimlane.md)).
- 단계가 여러 해에 걸치고 성과 지표가 붙는다 → **로드맵** ([type-roadmap.md](type-roadmap.md)).
- 날짜별 겹침이 중요하다 → **세부 추진 일정표** ([ko-schedule-table.md](ko-schedule-table.md)).

**상속:** [type-process.md](type-process.md) — 한 방향, 단계 번호, 연결선 없이 순서가 읽히는 선형 절차. 셰브론 도형과 행 머리 열은 [type-roadmap.md](type-roadmap.md)의 단계 헤더 규칙(끝·홈 16px, 끝이 다음 홈 16px 앞에서 멈춤)을 그대로 쓴다.

## Layout conventions

Canvas `viewBox="0 0 1112 368"` (6단계 기준; 5단계면 폭 172로 넓히고 1000 폭도 가능).

1. **행 머리 열:** x=32, 폭 96. 행마다 `ink @ 0.05` rect(`rx=6`) — 머리 셀 `구분`, 그리고 `주체`·`주요 내용`·`기간` 12px 600 + 아래 Mono 8px 눈썹(`ACTOR`, `TASKS`, 기간 행은 연도 `2026`).
2. **단계 열:** x=144부터 폭 140, gap 16 (x=144 / 300 / 456 / 612 / 768 / 924). 마지막 끝 x=1080.
3. **셰브론:** y=24, 높이 56. 첫 단계 `x0,24 x1,24 x1+16,52 x1,80 x0,80`, 이후 단계는 `… x0+16,52` 홈 추가. `ink @ 0.05` + `muted` 1px. 두 줄 — `STEP 01` Mono 8px tracked `muted` baseline 46, 단계명 14px 600 `ink` baseline 68, 보이는 몸통 중앙(홈 있는 단계 +8).
4. **주체 칸:** y=96, 높이 48. `paper` + `ink @ 0.12`. 주체명 12px 600 중앙, baseline y+28.
5. **주요 내용 칸:** y=152, 높이 88. 불릿 3개 baseline y+28 / +48 / +68, 4×4 `muted` 사각 x0+12, 글자 x0+24.
6. **기간 칸:** y=248, 높이 48. 왼쪽 소요 기간 12px 600(`4주`, `6개월`), 오른쪽 날짜 범위 Geist Mono 9px `muted`(`03.02–03.27`) 오른쪽 정렬.
7. **범례 줄:** y=320 헤어라인, baseline 348 — 절차 단계, 핵심 단계(작은 셰브론).

연결선·화살표는 없다. 셰브론의 끝과 홈이 순서를 말한다.

## 초점

accent 1개: **결과를 가르는 단계**(보통 평가 또는 선정)의 셰브론 — `accent-tint` 채움, `accent` 테두리, `STEP` 눈썹 `accent`. 단계명과 아래 칸은 중립으로 둔다.

## 한국어 표기

- 단계명 2~4자 명사(`공고`, `접수`, `평가`, `선정`, `협약`, `수행`).
- 주체는 기관 역할명(`전담기관`, `신청 기업`, `평가위원회`). 두 주체면 `전담기관·기업`. 116px 안.
- 주요 내용 불릿 8자 이내 명사형(`서면 평가`, `사업비 교부`) — 칸 폭 − 36 = 104px 안.
- 기간은 `N주`·`N개월` + 날짜 범위 `MM.DD–MM.DD`(연도는 행 머리 눈썹에 한 번).

## Complexity budget

- 단계 4~6개, 단계당 불릿 3개 이하, accent 1개.
- 7단계 이상이면 두 줄로 접지 말고 큰 단계로 묶는다(예: `선정·협약`).

## Anti-patterns

- **셰브론 사이 화살표.** 모양이 이미 방향이다.
- **주체를 색으로 구분.** 주체는 칸에 글자로 적는다; 색은 초점 하나에만.
- **문장형 내용**(`서면 평가를 실시합니다`). 개조식으로.
- **기간 없는 절차.** 신청자에게 가장 중요한 정보다.
- **셰브론 안에 3줄 이상.** 설명은 아래 칸으로.

## Checklist

- [ ] 셰브론 끝·홈이 16px이고 끝이 다음 홈 16px 앞에서 멈추는가?
- [ ] 모든 단계에 주체·내용·기간이 있는가?
- [ ] 불릿과 주체가 칸 폭 안에 들어가는가(폭 예산)?
- [ ] accent는 핵심 단계 셰브론 하나인가? 한글 12px 이상인가?
