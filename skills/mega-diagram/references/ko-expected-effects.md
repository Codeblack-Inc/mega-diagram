# 기대효과 (Expected effects · 정량·정성·파급)

**쓰는 곳:** 사업계획서·과제 제안서·예산 요구서의 **기대효과** 절. 왼쪽에 정량적 효과(큰 숫자 + 산출 근거), 오른쪽에 정성적 효과(개조식 3줄)를 나란히 두고, 아래 띠에 사업 범위 밖으로 번지는 **파급 효과**(경제·사회·기술)를 적는다. 평가위원이 "무엇이, 얼마나, 왜 그 숫자인가"를 한 장에서 확인하게 한다.

**쓰지 않는 곳:**

- 목표와 전략·과제의 위계를 보여 준다 → **전략 체계도** ([type-strategy-house.md](type-strategy-house.md)). 기대효과는 사업이 끝난 뒤의 결과만 다룬다.
- 연도별 목표치 추이 → **선** ([type-line.md](type-line.md)) 또는 로드맵의 성과 지표 행 ([type-roadmap.md](type-roadmap.md)).
- 실적을 목표에 대어 본다 → **불릿 차트** ([ko-bullet.md](ko-bullet.md)).
- 정량 효과가 하나도 없다 → 그림 대신 문단. 숫자 없는 기대효과 표는 비전의 반복이다.

**상속:** [type-strategy-house.md](type-strategy-house.md). 목표 카드의 KPI 문법(28px 숫자 + 14px 지표명 + 12px 근거), 연결선 없는 계층(위 = 직접 효과, 아래 = 파급), 기반 띠의 전폭 배치를 그대로 가져온다.

## Layout conventions

Canvas `viewBox="0 0 1000 496"`. 모든 구조 좌표는 4px 격자.

1. **두 패널:** y=24, 높이 48 + 3 × 80 = 288. 정량 패널 x=32, 폭 552 / 정성 패널 x=608, 폭 360 (gap 24). `paper` 채움, `ink @ 0.30` 1px 테두리, `rx=6`.
2. **패널 머리:** 이름 14px 600 (`정량적 효과`) x+16, baseline y+30. 오른쪽 끝에 Geist Mono 8px tracked 눈썹(`QUANTITATIVE`, `QUALITATIVE`). y+48에 `ink @ 0.12` 1px 가로줄.
3. **정량 행 (80 pitch):** 숫자 28px 600 x=56, baseline row+50. 지표명 14px 600 x=224, baseline row+34. 산출 근거 12px 500 `muted` x=224, baseline row+56. 행 사이 `rule` 헤어라인, 좌우 16 들여쓰기.
4. **정성 행 (같은 80 pitch):** 4×4 `muted` 사각 불릿 x+16, 제목 14px 600 x+28, 설명 12px 500 `muted`. 두 패널의 행 높이를 맞춰 줄이 가로로 이어져 읽히게 한다.
5. **파급 효과 띠:** y=336, 높이 88. 행 머리 x=32 폭 120 (`ink @ 0.05`, `파급 효과` 12px 600 + `RIPPLE` 눈썹). 셀 3개 x=168 / 440 / 712, 폭 256, gap 16, `paper` + `ink @ 0.12`. 셀 머리 `경제`·`사회`·`기술` 12px 600 y+28 + 오른쪽 Latin 눈썹, 불릿 2줄 baseline y+52 / y+72.
6. **범례 줄:** y=448 헤어라인, baseline 476에 `범례` + 항목(핵심 효과, 효과 구분, 파급 영역).

그리는 순서: 패널 → 패널 머리 → 초점 행 → 정량 텍스트 → 정성 → 파급 띠 → 범례.

## Node treatments

| 역할 | 채움 | 테두리 |
|---|---|---|
| 패널 | `paper` | `ink @ 0.30` |
| 핵심 효과 행 (초점) | `accent-tint`, 행 안쪽 8px 들여 `rx=4` | `accent`; 숫자도 `accent` |
| 파급 행 머리 | `ink @ 0.05` | 없음 |
| 파급 셀 | `paper` | `ink @ 0.12` |

**초점:** accent는 정량 효과 한 행(사업 타당성이 걸린 숫자, 보통 원가 절감액·매출)뿐이다. 정성 효과나 파급 효과에는 쓰지 않는다.

## 한국어 표기

- 숫자는 부호·단위 포함 6자 이내: `−32%`, `4.8억 원`, `+12%p`. 비율 차이는 `%p`로 쓴다.
- 지표명은 명사형 10자 이내(`연간 제조원가 절감`). 방향은 숫자 부호가 말하고 지표명에는 `감소`·`향상` 한 단어만.
- **산출 근거는 필수.** `현재값 → 목표값, 기준` 또는 합산식(`불량 손실 1.9억 + 에너지 1.2억 + 인건비 1.7억`). 합산식의 합이 숫자와 맞는지 확인한다.
- 정성 효과 제목 10자, 설명 한 줄(패널 폭 − 44px 안, 대략 24자).
- 파급 효과는 영역별 2줄, 14자 이내. 정량 효과를 다시 적지 않는다.

## Complexity budget

- 정량 3개, 정성 3개(각 2~4 허용; 두 패널의 행 수는 같게), 파급 영역 3개 × 2줄.
- accent 1개(핵심 정량 효과 행).

## Anti-patterns

- **근거 없는 퍼센트.** 평가위원이 가장 먼저 감점한다. 모든 숫자에 근거 줄을 단다.
- **정성 효과에 숫자 섞기.** 숫자가 있으면 정량 패널로 옮긴다.
- **파급 효과가 직접 효과의 반복.** 사업 범위 밖(협력사, 지역, 업계)으로 번지는 것만.
- **숫자마다 색칠, 신호등 색, 화살표 아이콘.** 숫자 크기가 이미 위계를 만든다.
- **패널 사이 화살표.** 정량과 정성은 인과가 아니라 병렬이다.

## Checklist

- [ ] 정량 숫자마다 산출 근거가 있고 합산식이 맞는가?
- [ ] 두 패널의 행 pitch(80)가 같은가?
- [ ] accent는 핵심 정량 효과 한 행뿐인가?
- [ ] 한글 12px 이상, 크기는 28/14/12(한글)·9/8(Latin mono)뿐인가?
- [ ] 파급 효과가 경제·사회·기술 영역으로 나뉘고 직접 효과와 겹치지 않는가?
