# 5 Forces 산업 구조 분석

**쓰는 곳:** 사업계획서·시장 분석 보고서·컨설팅 보고서의 "산업 환경 분석" 절. Porter의 다섯 가지 힘을 한 장에 놓는다 — 가운데 **기존 경쟁**, 위 **신규 진입**, 아래 **대체재**, 왼쪽 **공급자 교섭력**, 오른쪽 **구매자 교섭력**. 힘마다 강도(상·중·하)와 근거 두 줄을 적어, 산업이 얼마나 수익을 내기 어려운지를 읽게 한다.

**Base type:** [type-architecture.md](type-architecture.md) — 노드 박스, 같은 축 직선 연결선, 화살표 마커. 박스 내부(제목 · 칩 · 구분선 · 글머리표)는 [type-governance.md](type-governance.md)의 조직 박스와 같다.

## 쓰지 않는 곳

- **자사 내부 강점·약점**: SWOT — 5 Forces는 산업을, SWOT은 회사를 본다.
- **특정 경쟁사 비교**: 경쟁사 비교표 — [ko-competitor-matrix.md](ko-competitor-matrix.md).
- **거시 환경**(정책·경제·사회·기술): PEST는 네 칸 표로 충분하다.
- **힘 사이의 인과**(대체재가 늘어 구매자 교섭력이 커진다): 의존 관계도 — [type-dependency.md](type-dependency.md).

## Layout grammar

`0 0 1000 616` viewBox, 4px grid. 박스 5개 모두 240 × 112.

| 힘 | x, y |
|---|---|
| 신규 진입 위협 (위) | 380, 40 |
| 공급자 교섭력 (왼쪽) | 40, 228 |
| 기존 경쟁 (가운데) | 380, 228 |
| 구매자 교섭력 (오른쪽) | 720, 228 |
| 대체재 위협 (아래) | 380, 416 |
| 범례 | 헤어라인 y = 560, 기준선 592 |

- **화살표 네 개, 모두 바깥 → 가운데.** 같은 축 직선: 위 `(500,152)→(500,228)`, 아래 `(500,416)→(500,340)`, 왼쪽 `(280,284)→(380,284)`, 오른쪽 `(720,284)→(620,284)`. 라벨 없음 — 힘 이름은 박스에 있다.
- **선 굵기 = 강도.** 상 1.6 · 중 1.2 · 하 1 점선 `4,3`. 마커가 선 굵기에 비례해 커지므로 강한 힘이 저절로 무겁게 보인다.
- **박스 안:** 힘 이름(14px 600) x + 16, y + 28. 강도 칩은 오른쪽 위 x + w − 16 − 칩폭, y + 12, 높이 24, `rx=4`, 글자 12px — 박스 **안**에 있어야 한다(밖으로 나오면 라벨 마스크로 오인되고 다음 박스에 가린다). 구분선 y + 44, 글머리표 y + 70 · y + 90.
- **그리는 순서:** 화살표 → 박스(마스크 → 스타일 → 이름 → 칩 → 구분선 → 글머리표) → 범례.

## Treatments

| 역할 | Fill | Stroke |
|---|---|---|
| 기존 경쟁 (가운데) | `backend` (흰색) | `ink` 1.2 — 중심이지만 강조색은 쓰지 않는다 |
| 바깥 힘 | `backend` (흰색) | `ink @ 0.30` |
| 가장 큰 위협 (focal) | `accent-tint` | `accent`, 칩·화살표도 `accent` |
| 강도 칩 상 | 없음 | `ink` 1.2, 글자 600 |
| 강도 칩 중·하 | 없음 | `muted` 0.8, 글자 500 |

**Focal rule:** 강조는 가장 큰 위협 **하나**(박스와 그 화살표가 한 요소). 강도 상이 둘이라도(예: 기존 경쟁·구매자) 대응 전략이 걸린 쪽만 칠한다. 가운데 박스까지 칠하면 "무엇이 위협인가"가 흐려진다.

## Korean wording

- **힘 이름은 고정 용어**: `신규 진입 위협` · `대체재 위협` · `공급자 교섭력` · `구매자 교섭력` · `기존 경쟁`. 번역체(`새로운 진입자의 위협`)를 쓰지 않는다.
- **강도**는 `강도 상` · `강도 중` · `강도 하` 세 단계. 높음/보통/낮음, 별점, 5점 척도와 섞지 않는다.
- **근거 두 줄**, 명사형 ≤ 14자, 가능하면 숫자(`국내외 12개사 경쟁`, `클라우드 단가 연 5% 하락`). 240 박스에서 글머리표 여백을 빼면 12px 한글 약 16자가 한계.
- 범례 오른쪽 끝에 판정 시점과 근거 출처(`2026년 3분기 · 고객 32곳·업계 전문가 6인 인터뷰`).

## Complexity budget

- 박스 5개, 화살표 4개 고정. 여섯 번째 힘(보완재, 정부)은 넣지 않는다 — 필요하면 요약 카드나 본문.
- 박스당 근거 2줄. 세 번째 줄이 필요하면 박스 높이 132(4px grid 위)로 다섯 박스를 함께 늘린다.
- 강조 1개.

## Anti-patterns

- **힘마다 다른 색**: 강도가 색이 아니라 선 굵기와 칩에 있다.
- **화살표가 가운데에서 바깥으로**: 힘은 산업을 누르는 방향이다.
- **강도 없이 목록만**: 5 Forces의 결론은 "어떤 힘이 강한가"다.
- **사선 배치**(오각형·별 모양): 연결선이 사선이 된다. 십자 배치를 지킨다.
- **칩을 박스 테두리에 걸치기**: 다음에 그리는 박스에 가리고 geometry 검증에 걸린다.
- **그림 번호·캡션을 SVG 안에** — [mega.md](mega.md).

## Pre-output checklist

- [ ] 십자 배치, 박스 240 × 112, 좌표 모두 4의 배수?
- [ ] 화살표 4개가 모두 같은 축 직선이고 가운데를 향하는가?
- [ ] 선 굵기와 칩이 같은 강도를 말하는가(상 1.6 · 중 1.2 · 하 1 점선)?
- [ ] 칩이 박스 안에 완전히 들어가는가?
- [ ] 강조는 가장 큰 위협 하나?
- [ ] 근거가 명사형 ≤ 14자, 숫자 포함?
- [ ] 한글 12px 이상, 글자 크기 12 · 14만?
- [ ] light · dark · full 라벨이 같은가?
