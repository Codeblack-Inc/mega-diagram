# 양방향 막대 (Butterfly · 좌우 대칭 비교)

**쓰는 곳:** 같은 범주 축에 **두 집단을 좌우로 펼쳐** 비교할 때 — 연령대별 남·여(인구 피라미드), 지역별 도입 전·후, 항목별 찬성·반대. 가운데 범주 축을 두고 왼쪽 집단은 왼쪽으로, 오른쪽 집단은 오른쪽으로 막대를 뻗는다. 양쪽은 반드시 같은 척도다.

**쓰지 않는 곳:**

- 두 값의 **차이**가 메시지다 → **덤벨** (type-bar.md Variants · Dumbbell). 양방향 막대는 두 분포의 모양을 보여 준다.
- 집단이 셋 이상 → **묶은 막대** 또는 **누적 막대** ([ko-stacked-bar.md](ko-stacked-bar.md)).
- 양수·음수로 갈리는 하나의 값(증감) → 0 기준선 하나의 **발산 막대**. 가운데 범주 열이 필요 없다.

**상속:** [type-bar.md](type-bar.md) — 가로 막대, 0에서 시작, 초점 1개, 막대 패턴(`paper` 마스크 + 채움 + 1px 테두리).

## Layout conventions

Canvas `viewBox="0 0 1000 448"`.

1. **세 열:** 왼쪽 막대 영역은 x=432에서 왼쪽으로, 오른쪽은 x=568에서 오른쪽으로 각 320px. 가운데 136px(432~568)가 범주 축. 두 기준선 `ink @ 0.25` 1px.
2. **척도:** 양쪽 공통, 0~24,000명 → 320px (`k = 320 / 24,000`). 최댓값을 올림한 깔끔한 끝값을 고르고 한쪽 최댓값에 맞춰 따로 늘리지 않는다. 격자선은 8,000 간격 `ink @ 0.08`, 눈금 숫자는 마지막 행 아래 24px에 Geist Mono 9px, 양쪽 모두 바깥으로 커진다.
3. **머리글:** 각 영역 중앙에 집단 이름 14px 600(y=60)과 `합계 56,890명` 12px `muted`(y=78). 가운데에 `연령대` 12px 500 `muted`. 합계는 스크립트가 계산한다. 단위 `단위: 명`은 (32, 36).
4. **행:** 첫 행 y=96, pitch 44, 막대 높이 28. 범주 이름은 가운데 x=500, baseline y+18, 12px 600 — 폭 + 16 ≤ 136(assert).
5. **막대:** 왼쪽 막대 x = 432 − 값×k, 오른쪽 x = 568. `muted @ 0.15` + `muted` 1px. 두 집단을 색으로 나누지 않는다 — 위치와 머리글이 이미 구분한다.
6. **값 라벨:** 막대 바깥 끝에서 8px, 12px 400 `muted`(`18,640명`). 왼쪽은 `end`, 오른쪽은 `start`. 캔버스 32~968 안에 들어가야 한다(assert).
7. **범례 줄:** y=384 헤어라인, y=402 `LEGEND`, 항목 baseline 424 — 막대, 초점 막대, 오른쪽 끝에 `좌우 같은 척도 · 기준 시점`.

## 초점

accent 요소 1개: 이야기의 중심인 막대 하나(`accent @ 0.12` 채움 + `accent` 테두리, 값 라벨 `accent` 600). 한쪽 집단 전체를 accent로 칠하지 않는다.

## 한국어 표기

- 집단 이름은 `남성`·`여성`, `도입 전`·`도입 후`처럼 짝을 맞춘다. 시간 순서가 있으면 이전을 왼쪽에.
- 범주는 `10대`, `60대 이상`처럼 보고서 구간 표기. 6자 이내.
- 값은 천 단위 쉼표 + 단위(`3,240명`). 비율로 그릴 때는 머리글에 `구성비(%)`를 밝히고 합계 대신 모수를 적는다.

## Complexity budget

- 범주 4~10행, 집단 정확히 2개.
- accent 막대 1개.

## Anti-patterns

- **좌우 척도가 다름.** 짧은 쪽을 늘려 그리면 비교가 거짓이 된다. 한 척도, 범례 줄에 명시.
- **왼쪽 막대 길이에 음수 값 라벨(`−18,640`)** — 방향은 위치가 말한다. 값은 양수로.
- **집단별 색(파랑·분홍 등).** 색 고정관념이고, 위치가 이미 구분한다.
- **가운데 범주 열 없이 막대끼리 붙이기** — 라벨이 막대를 덮는다.
- **범주 순서를 값 크기로 정렬** — 연령·지역처럼 순서가 있는 범주는 그 순서를 지킨다.

## Checklist

- [ ] 집단이 정확히 둘이고, 좌우가 같은 척도인가?
- [ ] 막대 길이·합계가 같은 데이터에서 계산됐는가?
- [ ] 모든 막대 끝에 값 라벨이 있고 캔버스 안인가?
- [ ] 범주 순서가 자연 순서인가? accent는 막대 하나인가?
- [ ] 한글 12px 이상, 눈금 숫자 Geist Mono인가?
